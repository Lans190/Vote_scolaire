# Système de Vote Scolaire 2026

Application web pour l'élection des délégués élèves par les professeurs.

## 🚀 Déploiement sur Render

1. Connectez ce repository à Render.com
2. Utilisez le Blueprint avec render.yaml
3. Accédez à l'application via les URLs générées

## 🔧 Développement local

### Backend
```bash
cd backend
pip install -r requirements.txt
python app.py
